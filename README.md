# SAMASTHA - IELTS MOCK
### An AI-Powered IELTS Preparation Platform

---

## 📚 Project Overview
This repository contains the **Project Report**, **Presentation Slides (PPT)**, and **LaTeX Source Code** for the **SAMASTHA - IELTS MOCK** platform — an AI-integrated web application designed to simulate real IELTS examination scenarios.  
The system provides comprehensive module-wise testing in **Listening**, **Reading**, **Writing**, and **Speaking**, enriched with dynamic AI feedback, automated scoring, and performance analytics.

This work is **part of the final year B.Tech Project Submission** for Rajiv Gandhi University of Knowledge Technologies (RGUKT - Nuzvid), developed during my **long-term internship** at **Edubot Software and Services**.

---

## 🛠️ Technologies Used
- **Frontend:** React.js + Tailwind CSS
- **Backend:** Python (FastAPI / Flask)
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Tokens)
- **AI/NLP Services:**
  - OpenAI GPT APIs (for Writing evaluation and feedback generation)
  - Google Cloud Speech-to-Text API (for Speaking module transcription)
- **Deployment:** Vercel (Frontend), Render/Heroku (Backend hosting)

## 📈 Key Features
- Realistic IELTS Test Simulation (Listening, Reading, Writing, Speaking)
- Real-time AI Feedback on Writing and Speaking
- Band Score Estimation and Detailed Test Analytics
- User Test History and Retake Options
- Secure Login and Modular Test Navigation
- Fully Responsive Frontend Interface
- Admin Monitoring and Analytics Ready (Future Scope)
